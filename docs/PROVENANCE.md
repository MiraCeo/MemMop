# 来源记录

记录每个模块的**来源**，而不是许可证声明。目的：让"哪些是自己写的"成为可查的记录，而不是主张。

| 模块 / 资产 | 来源 | 说明 |
|---|---|---|
| 产品规格（SPEC.md） | **原创** | 本项目的设计与决策 |
| 文案与命名 | **原创** | 中文/英文两份文案库均自行撰写 |
| UI 结构（主页 / 设置 / 关于、四段条、折叠组） | **原创** | 设计出自本项目 |
| 进程占用表（指标、聚合方式、展示） | **原创** | 指标口径来自公开文档，实现自行编写 |
| 底层 API 知识（MEMORY-API.md） | **公开资料** | NtDoc、Microsoft Learn、phnt 头文件 |
| 内存区域的划分方式 | **参考** WMC / Mem Reduct | 属于事实层面（哪些系统调用存在） |
| 代码实现 | **从零编写** | 每个文件的首次提交即为其来源记录 |

## 关于参考项目

- **WinMemoryCleaner** — 1.x 的代码基础，GPL v3。2.x **不继承其代码**
- **Mem Reduct** — 仅作为底层 API 的第二份对照资料，GPL v2。**不继承其代码**

两者对 2.x 的贡献都只在"知识"层面：确认了哪些系统调用可用、各自的效果与代价。

## 维护规则

1. 新文件提交时，若其思路来自某个外部项目，在代码注释或本表中记录
2. 若一段代码是从某处复制或改写而来，**必须在此登记并遵守其许可证**
3. 本表的目标状态：所有条目均为"原创"或"公开资料"
