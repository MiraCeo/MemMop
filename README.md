# MemMop

一个面向 **Windows** 的内存管理工具。

> **本仓库从零开始，不包含 WinMemoryCleaner 的代码。**
> 前身是 [MemMop-Archived](https://github.com/MiraCeo/MemMop-Archived)（1.x，基于
> [WinMemoryCleaner](https://github.com/IgorMundstein/WinMemoryCleaner) 修改，GPL v3）。

---

## 要做什么

同样底层能力下，**更可信的交互**。

现有工具（WinMemoryCleaner、Mem Reduct）用的是同一批 Windows Native API，能力上差别不大；
而它们都没有解决一个更实际的问题：**用户看不懂自己在做什么、代价是什么、到底有没有效果。**

所以这个项目不做这些：

- 不做"让电脑变快"的承诺 —— 清理待机内存不会增加可用内存
- 不为了功能数量增加选项 —— 说不清代价的操作不做
- 不隐藏风险 —— 每个操作旁必须写明它会让什么变差

要做的是三件可验证的事：

| 标准 | 含义 |
|---|---|
| **效果真实** | 区分状态变化与性能收益，不用好看的数字代替实际效果 |
| **行为透明** | 告诉用户做了什么、为什么做、代价是什么 |
| **控制可靠** | 用户授权范围内的操作不被绕过 |

完整定义见 [docs/SPEC.md](docs/SPEC.md)。

## 界面

五个页签，固定 540×640 窗口，另有 320×212 紧凑视图。

| 页签 | 内容 |
|---|---|
| **主页** | 环形图（活动 / 已修改 / 待机 / 空闲）、可用内存、进程占用排行（前 12，每行可单独优化）、迷你趋势线、清理按钮 |
| **统计** | 内存曲线（1 分钟 / 5 分钟 / 15 分钟 / 1 小时四档）、上次清理的逐区域明细、清理记录、CSV 导出 |
| **设置** | 语言、字号、六个开关、清理区域（七项，每项写明代价）、自动清理（间隔 + 阈值滑块） |
| **白名单** | 按名称搜索添加、上下移动、删除；名单内的进程不参与「收缩程序驻留内存」 |
| **关于** | 版本与构建号、它是什么、怎么验证、技术信息、前身 |

托盘图标左键显示窗口，右键菜单：主页 / 设置 / 清理 / 退出。

## 状态

**.NET Framework 4.7.2 + WPF，单个 exe，约 260 KB，无外部依赖。**

| 已实现 | 说明 |
|---|---|
| 内存监测 | 四段构成与已提交，每秒刷新；数值由探针交叉验证 |
| 七个清理区域 | 待机缓存（全部 / 仅低优先级）、写回已修改内存、合并重复内存页、收缩系统缓存、注册表缓存整理、收缩程序驻留内存 |
| 清理结果 | 每个区域的实际释放量，测不出来就写「无变化」；明细在统计页 |
| 进程表 | 按专用工作集排序、按进程名聚合、前 12 名，可单独优化某个进程 |
| 自动清理 | 间隔（关闭 / 15 / 30 / 60 / 120 分钟）与占用阈值（关闭 / 75 / 80 / 85 / 90%），只执行保守子集 |
| 统计 | 内存曲线、清理记录、CSV 导出（区域名带稳定 ID，切语言不影响表格） |
| 白名单 | 按进程名、搜索过滤、排序、持久化 |
| 托盘 | 主题化菜单、tooltip 显示内存与上次清理 |
| 日志 | `%LOCALAPPDATA%\MemMop\memmop.log`，超过 1 MB 轮转 |
| 双语 | 简体中文 / English，运行时切换，无硬编码文案 |
| 图标 | 七尺寸（16–256），exe / 任务栏 / 托盘 / 关于页统一 |

**尚未完成**：

- 安装程序与代码签名（当前只发 exe，首次运行会触发 SmartScreen）
- 自动更新

## 构建

```powershell
pwsh -File build.ps1
```

产物：`dist\MemMop.exe`（单文件）。`-SkipTools` 跳过截图工具，`-Configuration Debug` 换配置。

## 验证

```powershell
dotnet run --project tools/probe -c Release
```

`tools/probe` 编译与主程序相同的 `Core` 和 `ViewModel` 源码，在**不提权、不开窗口**的情况下检查：
内存四段是否加得起来、双语目录有没有空条目、七个区域是否齐全、日志能否写出、热键默认值。

**它不覆盖清理本身** —— 那些调用需要管理员权限，探针做不到，也不假装做到。

另外两个工具：

| 工具 | 用途 |
|---|---|
| `tools/shot` | 离屏渲染全部界面到 PNG（中英双语、21 张），并自检没有写注册表 |
| `tools/measure` | 扫像素量包围盒，用于核对布局尺寸 |

细节见 [docs/HANDOFF.md](docs/HANDOFF.md)。
