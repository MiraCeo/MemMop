# MemMop

一个面向 **Windows** 的内存管理工具。

> **本仓库从零开始，不包含 WinMemoryCleaner 的代码。**
> 前身是 [MemMop-Archived](https://github.com/MiraCeo/MemMop-Archived)（1.x，基于
> [WinMemoryCleaner](https://github.com/IgorMundstein/WinMemoryCleaner) 修改，GPL v3）。

---

## 要做什么

同样底层能力下，**更可信的交互**。

现有工具（WinMemoryCleaner、Mem Reduct）用的是同一批 Windows Native API，能力上差别不大；
而它们都没有解决一个更实际的问题：**用户看不懂自己在做什么、代价是什么、到底有没有效果。**

所以这个项目不做这些：

- 不做"让电脑变快"的承诺 —— 清理待机内存不会增加可用内存
- 不为了功能数量增加选项 —— 说不清代价的操作不做
- 不隐藏风险 —— 每个操作旁必须写明它会让什么变差

要做的是三件可验证的事：

| 标准 | 含义 |
|---|---|
| **效果真实** | 区分状态变化与性能收益，不用好看的数字代替实际效果 |
| **行为透明** | 告诉用户做了什么、为什么做、代价是什么 |
| **控制可靠** | 用户授权范围内的操作不被绕过 |

完整定义见 [docs/SPEC.md](docs/SPEC.md)。

## 状态

**功能已对齐 1.x。** .NET 8 + WPF，单文件，无外部依赖。

| 已实现 | 说明 |
|---|---|
| 内存监测 | 四段构成（活动/已修改/待机/空闲）与已提交，每秒刷新；数值由探针交叉验证 |
| 七个清理区域 | 待机缓存（全部/仅低优先级）、写回已修改内存、合并重复内存页、收缩系统缓存、注册表缓存整理、收缩程序驻留内存 |
| 清理界面 | 每个区域一行：勾选、名称、代价说明、上次结果（有释放/无变化/失败） |
| 托盘 | 左键显示、右键菜单（主页/设置/清理/退出）、关闭到托盘、首次提示 |
| 自动清理 | 定时与低内存阈值；自动只执行安全子集（可在设置里放开） |
| 进程表 | 按专用工作集排序、按进程名聚合、前 10 名 |
| 排除名单 | 按进程名、搜索过滤、持久化 |
| 双语 | 简体中文 / English，运行时切换 |

**尚未完成**：图标（仍用系统默认）、安装/发布流程、签名。

## 构建

```powershell
pwsh -File build.ps1
```

产物：`dist\MemMop.exe`（单文件）。

## 验证

```powershell
dotnet run --project tools/probe -c Release
```

`tools/probe` 编译与主程序相同的核心源码，可以在不提权、不开窗口的情况下验证内存数值、清理结果、
策略规则与语言切换。
